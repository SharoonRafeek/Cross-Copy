## Why no-install matters

Install restrictions are common on work laptops and shared devices.

A web route bypasses app approvals and keeps setup almost instant.

## How to use

Open the same CrossCopy route on both devices.

Paste text into one session and copy from the other.

Bookmark frequently used routes for recurring workflows.

## Frequently Asked Questions

### Do I need an account?

No account is required.

### Can I use this on corporate machines?

Usually yes if browser access is allowed, but follow company policy.
